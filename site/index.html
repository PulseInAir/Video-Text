FAQ

Reasonable questions.

Is it actually free?

Yes, and open source. No paid tier, no usage cap, no account. Recognition runs on your own machine, so there are no server bills to pass on to you.

Does it work on Netflix or Prime Video?

No. DRM-protected players hand back blank pixels to every browser extension — a protection built into Chrome that nothing can work around. Video Text detects it and tells you, instead of quietly saving nothing.

How accurate is it, honestly?

Strong on clean subtitles. Weaker on small, blurry or heavily compressed text — that's the nature of OCR, not a bug we're hiding.

If a result looks off: draw a tighter box, raise the upscale setting to 3–4×, or switch layout mode to “single line”. And every capture stays editable, so fixing a stray character takes a second.

Can it transcribe speech?

No — it reads text that is visually on screen, not audio. For videos with burned-in subtitles that amounts to the same result, which is exactly what Auto mode is built for.

Which languages?

English ships in the box. The underlying engine supports 100+ languages and more models can be bundled — open an issue if you need a specific one.

Why does it run on every site?

Because a video can be on any page. The content script only draws the selection overlay when you press the shortcut or click the icon — it reads nothing from the page and sends nothing anywhere. The extension requests no broad host permissions at all.
