Why it exists

Text in a video isn't text

You can't select it, search it, or quote it. Video Text fixes that with on-device OCR — no uploads, no waiting on a server.

⌗

Select like a screenshot

Drag a box over any part of the frame. Move it, resize from the corners, or grab the whole video at once.

⚡

Auto-capture transcripts

Turn on Auto and it reads subtitles as they appear, skipping repeats — then export the lot as a timed .srt.

🔒

Nothing leaves your browser

The OCR engine and language model ship inside the extension. No API keys, no accounts, no network calls.

✎

Fix it before you save

OCR isn't perfect. Every result is editable inline, in the panel and again in your library.

⏱

Timestamps that work

Captures remember where they came from, so links jump back to the exact second and subtitle cues line up.

◫

Searchable library

Everything you grab is kept locally. Search it, filter by site, edit, and export any subset you like.

How it works

Four steps, about ten seconds

No setup, no sign-in. Install it and it just works on the next video you open.

Open a video

Any site with a normal HTML5 player — YouTube, TikTok, a lecture page.

Press Alt+S

A selection box appears, already sitting over the subtitle area.

Frame the text

Drag to move, pull the corners to resize. Tighter boxes read more accurately.

Grab it

Text lands in a panel you can edit, copy, save, or export in eight formats.

Export

Eight formats, one click

Subtitle files carry real timings derived from the video, so they load straight into VLC, Premiere or YouTube's caption editor.

FAQ

Questions

Is it really free?

Yes, and open source. No paid tier, no usage limits, no account. Because OCR runs on your own machine there are no server costs to pass on.

Does it work on Netflix or Prime Video?

No. DRM-protected players hand back blank pixels to every browser extension — a protection built into Chrome itself that nothing can work around. Video Text detects this and says so rather than silently saving empty text.

How accurate is it?

Very good on clean subtitles; less so on small, blurry or heavily compressed text. If a result looks wrong, draw a tighter box, raise the upscale setting to 3–4×, or switch the layout mode to “single line”.

Every capture is editable, so fixing the odd character is quick.

Can it transcribe the audio?

No — this reads text that's visually on screen, not speech. For burned-in subtitles that amounts to the same thing, which is what Auto mode is for.

Which languages?

English ships in the box. The engine supports 100+ languages, and additional models can be added — see the repo if you'd like one included.

Why does it need permission for every site?

So the selection overlay can appear on whichever site you're watching a video on. It's the same access any ad blocker needs. Nothing is collected or transmitted — you can read the code.
