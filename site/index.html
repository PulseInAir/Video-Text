02Capabilities

Text on screen, put to work

Pause, squint, type, scrub back because you missed a word. Video Text replaces that loop with a rectangle — and keeps everything it reads.

01  Selection

Grab any region of the frame

Drag a box over subtitles, a slide, a code snippet or a sign in the background. Move it, resize from the corners, or take the whole video at once.

02  Transcripts

Auto-capture while it plays

Leave Auto running and each new subtitle is read as it appears, with near-duplicate frames skipped. Export the result as a properly timed .srt.

03  Library

Everything you grab is kept

Captures are stored locally with their source and timestamp. Search them, filter by site, edit any line, and export whatever subset you need.

04  Privacy

Nothing ever leaves the browser

The recognition engine is bundled inside the extension and runs offline. No servers, no API keys, no network requests — it works on a plane.

03Method

Engineered to stay out of the way

Install it once and it works on the next video you open.

Step 01

Open a video

Any site running a standard HTML5 player — a YouTube lecture, a TikTok clip, a course page, an internal training video.

Step 02

Press Alt S

The overlay opens with a selection box already positioned over the usual subtitle strip, and the video pauses so you have a still frame.

Step 03

Frame the text

Drag inside the box to move it, pull a corner to resize. Tighter boxes around just the text read noticeably more accurately.

Step 04

Grab, edit, export

Text lands in a panel you can correct inline, then copy, save to the library, or export in any of eight formats.

06Under the hood

Built to run entirely on your machine

No cloud dependency means no latency, no quota, no privacy trade-off.

Recognition

Bundled OCR engine

A WebAssembly build of Tesseract ships inside the extension along with its language model, so recognition never depends on a network call.

Accuracy

Frame preprocessing

Each capture is upscaled and contrast-normalised before recognition — a measurable improvement on compressed or low-light video.

Permissions

Least privilege

No broad host permissions are requested. The overlay activates only on the tab you invoke it on, and reads nothing from the page itself.

07Questions

Reasonable questions

Q1Is it actually free?

Yes, and open source. No paid tier, no usage cap, no account. Recognition runs on your own machine, so there are no server costs to pass on.

Q2Does it work on Netflix or Prime Video?

No. DRM-protected players hand back blank pixels to every browser extension — a protection built into Chrome that nothing can work around. Video Text detects it and tells you, instead of quietly saving nothing.

Q3How accurate is it, honestly?

Strong on clean subtitles. Weaker on small, blurry or heavily compressed text — that is the nature of OCR, not something being hidden here.

If a result looks off: draw a tighter box, raise upscale to 3–4×, or switch layout mode to “single line”. Every capture stays editable, so fixing a stray character takes a second.

Q4Can it transcribe speech?

No — it reads text that is visually on screen, not audio. For videos with burned-in subtitles the outcome is much the same, which is what Auto mode is built for.

Q5Which languages?

English ships in the box. The underlying engine supports over 100 languages and further models can be bundled — open an issue if you need a specific one.

Q6Why does it run on every site?

Because a video can be on any page. The content script only draws the selection overlay when you press the shortcut or click the icon; it reads nothing from the page and sends nothing anywhere. No broad host permissions are requested at all.
